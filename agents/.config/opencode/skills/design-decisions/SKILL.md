## Triggers

Load when:
- User asks "how should I", "best approach"
- Multiple implementation paths need evaluation
- Hitting a decision point

## Workflow

1. Define specific decision
2. List constraints
3. Generate 2-3 approaches
4. Compare trade-offs
5. Recommend one
6. Document decision
